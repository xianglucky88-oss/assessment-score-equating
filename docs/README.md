# 成绩数据契约与版本维护包

本目录是考试机构移交给维护者的**契约正文与维护资产**。它从当前代码的实际
数据流整理而成，不是 README 的复述：README 说明"怎么运行"，这里规定
"数据意味着什么、改动会影响什么、如何安全地改"。

## 文档地图

| 文档 | 回答的问题 |
|---|---|
| `contract/rules-catalog.md` | 规则目录：数据流各阶段、原始事实 vs 派生结果、决定历史报告的因素、全局语义、测试实际覆盖范围 |
| `contract/compatibility-matrix.md` | 题目替换 / 键修订 / 缺考违规状态 / 舍入变化时的兼容分级、影响面与回滚步骤 |
| `contract/ambiguity-cases.md` | 一组最小但互相矛盾的用例，暴露当前契约的歧义与待裁决问题 |
| `maintenance/review-checklist.md` | 变更评审清单（评审人逐项作答） |
| `maintenance/change-record-template.md` | 变更记录模板（一变更一记录） |
| `maintenance/pre-release-confirmation.md` | 发布前人工确认点 |
| `../fixtures/contract/` | 歧义用例输入与快照（文档资产，可用脚本复核） |
| `../tools/regen_contract_snapshots.py` | 快照再生成 / 校验脚本 |

## 标注约定（全部维护文档通用）

- **【已验证】**：对当前代码实际运行确认的行为，附代码位置。
- **【未裁决】**：契约歧义，需评审裁决；裁决前不得当作契约事实。
- **【建议】**：本维护包提出的管理约定，不是现状。

## 契约版本约定【建议】

- 当前契约版本：**1.0**（本维护包首次固化现状行为）。
- L1 值变更（schema 不变、部分值变）→ MINOR +1；L2 破坏性变更（schema 或
  全局语义变）→ MAJOR +1；L0 不变版本。
- 版本号只存在于文档与变更记录中；**当前输入与输出数据里没有任何版本字段**，
  在数据中加版本字段属契约新增（L2），需走变更流程。

## 使用边界

- 本包描述的是**当前代码**的行为；代码变更后，【已验证】条目必须重新验证，
  快照必须再生成。
- 本包不包含对未来实现的承诺；凡涉及"复核环节""版本字段""状态语义"的内容，
  现状均为**不存在**，仅作为待裁决或建议出现。
